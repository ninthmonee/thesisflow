**执行约定**

- 保留现有研究入口，新增入口独立验收后再切换。
- 新增数据库和导出器不在导入模块时写入真实用户数据。
- 每批记录实际检查与限制；模型/行情/资金缺失不能用模拟数值掩盖。
- Python 质量沿用 Ruff/pytest；前端使用 Oxlint、tsgolint、Oxfmt、TS7、Vitest 和必要浏览器验收。
