**本机工作台运行说明**

当前实施与验收进度见 [web-execution-status.md](web-execution-status.md)。当前版本支持账号登录与独立个人工作区，使用独立目录，不覆盖旧 CLI/Web 的结果。

**安装和检查**

要求 Python 3.13、Node 24 和 uv。本次使用 Python 3.13.3、Node 24.22.1、npm 11.19.1。项目根执行；首次先创建后端虚拟环境：

```bash
uv venv --python 3.13 backend/.venv
uv pip install --python backend/.venv/bin/python -r backend/requirements.lock
uv pip install --python backend/.venv/bin/python -e 'backend[web,dev]'
cd frontend
npm ci --ignore-scripts
npm run vendor:patch
cd ..
backend/.venv/bin/python backend/scripts/export_openapi.py --check
cd frontend
npm run check
cd ..
backend/.venv/bin/python backend/scripts/package_workbench.py --skip-build
```

已有 `backend/.venv` 时跳过创建命令。`backend/requirements.lock`记录本机已验收的精确Python环境；部署到不同平台需重新核查可选依赖。所有Python源码、测试、迁移、环境文件与工具在backend；React和旧前端源码在frontend，运行数据/契约/文档仍分别在根data/contracts/docs。backend/tradingagents/web/ui和static仅为生成资源。原根.venv已迁出，不再作为启动依赖。

依赖精确版本和 TypeScript 7 上游声明补丁说明见 [frontend/README.md](../frontend/README.md)。契约改变时先运行导出器（去掉 `--check`），再运行 `npm run api:generate`，最后运行完整检查。不要手动修改生成代码。

**启动和停止**

在项目根运行 `./start-workbench.command`，或在 macOS 双击此文件。浏览器访问 `http://127.0.0.1:8001/workbench/`。该脚本拥有一个 API 和一个独立研究 worker；在启动终端按 Ctrl+C 同时停止两者。端口已被占用时拒绝再启动一个 worker。

需要排查进程时可分别启动，下列两个命令必须使用相同数据库和研究目录：

```bash
backend/.venv/bin/python -m tradingagents.web.server --port 8001 --state-dir data/web/development --durable-research
backend/.venv/bin/python -m tradingagents.web.workers.research --database data/web/development/web/workbench.sqlite3 --artifacts data/web/development/web/research
```

浏览器关闭不停止研究。API 重启后读取持久化状态；worker 异常退出由租约识别为中断。恢复需要有效、兼容的完整检查点；没有检查点时使用“重新研究”。正在进行的模型/工具请求只能在可中止边界取消。

本地 Agent 模式由同一 worker 按需启动受控 Runtime 子进程；这不是第二套工作台，也不需要额外启动一个研究 worker。该模式当前不开放会话恢复，取消和超时会请求中断并回收本次进程组，不影响用户其他 Codex 会话。

前端源码修改后重新运行 `backend/scripts/package_workbench.py` 并刷新浏览器。只修改后端时需重启 API/worker；真实研究运行期间应先等它完成，避免人为中断。

**首次设置、开放注册和账号管理**

首次升级到账号版本后，页面进入“创建管理员账号”。本机所有者先在自己的终端运行下面的命令，复制输出的一次性初始化凭证到页面，再自行设置用户名、显示名称和密码。数据库路径必须与启动的 API 和 worker 一致；使用自定义状态目录时替换此路径。

```bash
backend/.venv/bin/python backend/scripts/account_setup.py --database data/web/development/web/workbench.sqlite3 --show-token
```

这条命令只供本人在本机执行。不要把输出发到聊天、截图或代码仓库；页面的公开会话接口不会返回该凭证。未使用的凭证如需重置，可由本人给同一命令增加 `--rotate`。管理员创建成功后凭证失效，命令会提示使用登录页面。

首个管理员接管原有本机工作区，自选、主题、研究历史和已有连接保持原归属。普通注册不能在初始化之前抢占这个工作区。默认开放注册，无需邀请码；初始化后，朋友可从登录页“立即注册”创建账号并自动登录。新账号有自己的空自选分组和独立研究记录，通用预置主题仍可使用，不复制主人的历史、模型连接、数据账号或密钥。

用户名为3–32位英文字母、数字、点、下划线或短横线，首位须为字母或数字，保存为小写。密码为12–128个字符，可使用空格和中文，不能全为空白。密码不回显、不写入浏览器持久缓存；浏览器仅持有 HttpOnly 会话 Cookie。页面读取完登录状态后才加载工作区。

点击顶栏账号名称进入 `/workbench/account`：可查看当前账号与工作区、修改密码、退出所有会话。改密须验证当前密码，成功后当前浏览器获得新会话，其他设备的旧会话失效。“退出所有会话”包含当前浏览器；普通顶栏“退出”只结束当前会话，不取消已经提交的研究。管理员同页可显式保存“开放注册”或“关闭注册”；关闭只阻止新账号注册，已有账号仍可登录。

会话最长7天，连续12小时没有业务访问后失效；仅轮询登录状态不会延长空闲时间。登录过期、退出或切换账号时，前端取消旧查询和事件流、清理查询及变更缓存，重新按当前用户和工作区读取；其他标签页也会重新确认身份。工作区预期标识用于防止跨标签切号回填，实际权限始终由服务端会话决定。旧 Web API、研究报告和事件接口同样受账号归属检查。

每个账号最多同时保留3个待处理研究（排队、运行和取消中合计），服务全局最多50个排队研究；达到上限时先等待或取消已有任务。API 内的用户服务资源池容量为32，按空闲状态回收，繁忙时可能要求稍后重试；这不是32个注册账号的上限，也不承诺32个研究并行执行。研究仍由独立 worker 运行，模型请求预算另按每次研究设置。

## Codex Runtime 独立研究

入口为 `/workbench/settings/runtimes`。首个适配器使用 Codex app-server 的 stdio 协议，当前支持并检测 Codex 0.164.x；其他版本必须通过适配器版本检查，不能仅因程序存在就视为可用。原有 Python/LangGraph 12角色研究仍可正常选择。

本机 Runtime 目前只允许原工作区主人配置和执行。朋友账号使用自己的 API 模型进行内置研究，不继承主人的程序权限或认证；朋友个人电脑连接器尚未实现。这里的“服务器本机”指运行后端与 worker 的机器，不等于远程访问者的浏览器所在电脑。

1. 在“电脑与运行环境”点击“添加运行环境”，填写连接名称和精确模型 ID。程序路径可以留空自动发现，也可填受支持 Codex 可执行文件的真实路径；不能填写 shell 命令、参数或任意脚本。
2. 选择认证来源。“本连接专属 Codex 登录”使用系统管理的独立 `CODEX_HOME`；先保存连接，再复制该连接显示的登录命令，由本人在自己的终端完成授权。命令明确要求 Codex 使用系统密钥库，不读取或搬运现有 Codex、HiFox 或 ChatGPT 模型连接的 OAuth Token。页面不接收 Token。
3. 也可选择“我配置的 Responses 模型连接”。先在模型设置中保存并检测自己的连接与模型，只支持 Responses 协议、聊天及工具调用检测通过、额外 `parameters` 为空的模型配置。此处复用地址、显式认证和模型 ID，思考档位单独在 Runtime 中设置；不支持的参数明确拒绝，不会静默丢弃。ChatGPT 模型连接的 `oauth_local` 不能搬运到 Runtime。
4. 启用连接并点击“检测环境”。检测读取程序版本、协议、独立授权状态和模型清单，不启动研究或真实模型推理。未授权、模型不在清单或能力不足时，按页面原因修正后重测；检测通过也不等于已验证研究结论或供应商推理权限。
5. 点击该连接的“发起研究”，或进入个股研究并选择“本地 Agent · 独立研究”。核对股票、美东日期、目标、期限、语言和运行环境；可输入最多4000字符的补充研究要求。金融工具次数默认40、最多100，执行时长和可获得的 Token 预算独立设置。
6. 显式点击“启动本地 Agent 研究”后才创建任务并调用模型。查看实际执行事件、请求/实际模型、来源证据、研究报告及 HTML/Markdown 导出。内置12角色路径不会套在这个独立 Agent 上。

当前 Runtime 只开放六类只读金融工具：固定标的和日期的历史 OHLCV、技术指标、公司概况/财报三表/内幕人交易、股票新闻样本、FRED 宏观序列，以及用户显式附加并冻结的研究资料。期权、ETF份额流和主题等可作为已冻结补充资料读取，不表示 Runtime 已获得任意期权、ETF或全市场接口。工具通过当前账号被冻结的数据连接取数，不向 Codex 下发供应商密钥。缺少来源时保留缺失和失败说明。

运行使用独立目录、受控配置和只读沙箱；仅暴露上述动态工具，禁止 shell、文件操作、子 Agent、外部 MCP、插件和网页搜索等未授权能力。新审批或未知服务请求默认拒绝，不能用提示词增加权限。程序、模型、授权或绑定连接变化后必须重测；排队或运行中的冻结引用不匹配时停止，不回退其他账号或模型。

Runtime 的结构化 JSON 报告必须与任务的股票和日期一致，引用只能指向本次已经捕获的 `snapshot:<id>`。产物会保存概览、分析、多空观点、风险和原始结论；本阶段强制保留为未经独立核验的研究观点，**不发布有效评级、已验证目标价或仓位**。来源捕获成功与模型观点正确是两项不同判断。

模型内部请求次数可能未知，已报告 Token 与工具次数分别记录，不把未知当作零，也不据此推算费用。取消或超时不会撤销已发生用量；连接中断、启动结果不确定或上游失败不会自动重启另一轮研究。当前不支持 Runtime 会话恢复；“重新研究”会保留执行方式和连接供重新核对，但创建的是新任务，可能产生新的模型用量。

0012迁移新增 Runtime 连接表，不自动创建或启用真实连接。恢复备份后 Runtime 连接全部停用、检测失效，独立认证目录不在恢复包内；不能通过恢复沿用旧机器的登录。本机授权模式在恢复工作区被阻止，需重新绑定当前账号的显式 API 模型并检测。原有12角色检查点继续受原图/代码兼容校验保护。

本批已用真实 Codex `0.164.0-alpha.11.1` 和隔离的本机假 Responses 服务验证 stdio 握手、动态工具、事件、产物和中断，不使用厂商密钥或真实模型推理。实际供应商调用由本人完成上述独立授权或 API 配置后，显式启动研究验证。

离线回归使用 `PYTHON_DOTENV_DISABLED=1 backend/.venv/bin/python -m pytest backend/tests -q`，避免本机 `.env` 改变CLI测试默认配置；部分认证测试需要允许本机回环端口，普通测试仍阻断外部网络。Runtime的真实CLI集成测试需另行显式选择integration标记，使用独立临时目录和本机假Responses服务。

**模型配置**

在 `/workbench/settings/models` 选择服务预设或“自定义模型服务”，填写供应商显示名、连接名称、API基础地址和协议。可显式选择OpenAI Chat Completions、OpenAI Responses、Anthropic Messages、Google GenAI；兼容服务不必使用预设厂商名称。任意私有协议需要新增适配器，不能只靠填写地址兼容。

本机所有者可选择“ChatGPT 本机订阅授权”连接，使用本机已有OAuth授权；页面只显示授权状态和可复制的CLI登录/退出命令，不接受粘贴Token，不把订阅改为API计费。该连接只限原本机所有者，朋友注册的账号不能读取、绑定或借用此授权，需要自行配置支持的模型API服务。先保存连接、填写实际模型ID并分别检测聊天/工具能力，再绑定研究角色。授权状态可用不代表模型与工具已经检测通过；切换本机OAuth账号会使旧检测/运行身份不再匹配。OAuth令牌沿用原有0600本机授权文件，API Key与自定义请求头使用系统密钥库。

认证支持API Key、仅自定义请求头或明确无需认证；请求头值与Key均写入系统密钥库，不回显。不要把密钥放在名称、地址query或额外请求体中。服务预设切换会清除表单密钥，避免误投其他厂商。

先保存连接，再新增模型并填写实际模型ID，可设置top_p/seed/stop及受限额外请求体；检测聊天和工具能力，最后在模板中给默认模型及各角色分配模型。每个角色可覆盖默认模型；保存为新模板版本后，已创建任务继续使用冻结版本。

API Key 通过本机系统 Keychain/keyring 保存，引用归属于当前用户与工作区，页面不回显密钥。更换密钥后需重新检测。聊天与工具能力分别检测；按实际启用角色预检：技术、新闻、基本面分析师需要工具能力；社交情绪预取后只需聊天能力。未选择分析师的覆盖模型不会阻断本次研究，实际基础辅助模型仍检查聊天能力。仅原本机所有者在未配置模板时保留已有本机配置兼容路径；新注册账号必须绑定自己的模型配置，不继承进程环境中的Key或主人的ChatGPT OAuth。凭据存在性检查不等于调用成功。

研究清单记录运行代码、提示词、状态结构与关键运行依赖的内容签名。升级后不恢复签名不一致的旧研究，使用“重新研究”创建新运行；已完成报告仍可读取。

**研究角色与决策路径**

启动研究页的“查看12角色决策路径”可跳转到可视化；模型设置中的同名按钮查看当前配置草稿；任务详情的“研究决策路径”页签对照该任务的阶段与报告。查看这些内容不调用模型、不保存配置，也不创建研究任务。

12种分工为：技术、基本面、新闻、情绪分析师；多头、空头研究员；研究经理；交易员；激进、保守、中立风险分析员；组合经理。所选1–4位分析师并行取证、工具循环后汇合，多空双方交替各depth轮，研究经理汇总、交易员提出计划，风险按激进→保守→中立循环各depth轮，最后组合经理形成决策和评级。12种角色可共用模型或分别覆盖，研究经理/组合经理默认deep，其余默认quick；模型请求次数还受工具、补充响应和条件反思影响，不能理解为固定12次调用。

角色节点展示职责、输入输出与模型来源。创建页按所选模板或本机默认预览，模型设置按未保存草稿预览；历史任务只读取运行清单中冻结的模型引用，不用当前设置填补未知历史模型。角色图解释当前引擎拓扑，旧运行没有冻结独立拓扑版本；历史叠加显示已保存的运行信息。

当前持久事件只有阶段、报告和累计用量，没有精确角色起止/轮次事件。图中“已有产出”“当前阶段”和未选择状态不等同逐角色实时运行或全部辩论轮数完成；失败/取消时已保存报告仍可查看。流程中的交易计划和记录决策不会发出券商订单。

辅助Memory Log不计入12个角色：它与分析师并行，尝试结算到期历史、必要时用quick模型反思，读取的经验仅供组合经理消费。当前Web按运行/尝试隔离记忆日志，不承诺跨研究共享经验；memory_note仅是诊断说明。结束后的评级解析和报告归档也不属于新增模型角色。

**数据和行情口径**

`/workbench/stocks`同时提供自选跟踪表和可收起的行情图表。顶部选择器切换已关注的股票/ETF；列表中的“图表”打开对应标的并保留周期、指标和SPY对比。收起图表会卸载图表面板，列表观察继续可用。查看状态保存在URL，刷新可恢复。

“添加股票 / ETF”通过弹窗选择目标分组、搜索真实证券并加入，已有成员不能重复加入同组；也可只查看行情。分组原有的新增、重命名、排序和移除撤销保留。跟踪表支持代码/公司/备注搜索、分组、仅收藏及数值排序；收藏和备注按当前用户与证券保存，跨分组共享，移除后重新关注仍保留。

跟踪搜索在本地即时过滤，按回车或搜索按钮将完整条件写入URL；清空立即清除URL条件。切分组、排序、收藏筛选或证券时一并保留当前完整搜索词。刷新数据可能复用限流或供应商缓存，列表来源接收时刻与本次聚合时刻分别显示；“规则依据”中可逐证券核对。

跟踪表价格为**最近完整日收盘**，与图表可能显示的当日未完结柱不同。`tracking-v1`使用最近65个完整XNYS交易日、同一来源/feed及原生调整口径：MA20/MA50、Wilder ATR14、前20日高低观察通道。波动1–5级来自ATR占收盘价比例的固定阈值1%/2%/3%/5%，不代表公司质量、估值或信用评级。

仅价格突破前20日通道且MA20/MA50同向、数据完整有效时显示波动参考：向上情景为收盘价+2ATR目标、收盘价−1.5ATR保护；向下情景反向计算。结果必须为正且方向正确。数据过期、缺口、无效或不足时不展示目标/保护，保留质量、日期和缺失说明。“规则依据”可查看公式、窗口覆盖与来源。这是可核对的固定机械观察，未验证预测胜率；当前不提供自定义技术策略或自动下单。

Yahoo 数值行情用于个人本机试用。价格标签是供应商 K 线收盘字段；当前没有逐笔、NBBO、盘口或实时延迟 SLA。界面显示来源、feed、UTC/ET 时间、调整口径和数据质量。分钟缺柱与缺失值不补成虚假价格/成交。

**2026-10-26 研究质量与复核**

执行完成只说明运行结束。研究详情另列证据资格：可用、降级、证据不足、未核验。有效评级至少要求同证券、正确完整交易日、有限且一致的OHLCV价格，以及本次所选维度的可解析来源；失败与未知结构保留缺口。历史研究没有当时捕获记录时保持未核验，原报告与原始模型判断仍可查看，不能据此补造证据。结构化目标价、保护价与仓位本轮均不自动授予有效资格；报告原文中的模型提案仍需人工审视。

工具证据页按25条分页。请求只保存白名单参数，来源数据时点与接收时间分开；正文为有界数值/标题链接/社交摘录，需主动勾选读取。保存内容哈希并校验文件完整性，未知结构不保存原文。此能力不等于已归档全部原始输入，尚不提供完整输入一致的跨模型公平复跑。

Web分析日期按America/New_York确定，提交和运行时日期保护一致，不跟随上海午夜提前到下一天；CLI未设置此运行上下文时保持原有日期行为。启动表单可指定研究目标、数天至数周/1–6个月/6个月以上研究周期，以及当前证券是否持有。每个角色收到共同意图；没有数量、成本、现金与其它持仓时不会假定完整组合。高级预算包含模型请求次数、Token和累计执行时间；恢复尝试继续累计，不重置额度。Jev辅助模型每次真实POST和重试也计入请求预算；来源未报告Token时显示未知，不以0代表免费。已在途请求可能在取消/达到Token阈值后完成，已有消耗继续登记。

“重新研究”先回到表单，选择按当前日期/配置或恢复原参数，再核对提交；不直接收费调用。原模板缺失时必须重新选择。完成/失败/取消后默认展示结论，运行中默认展示流程。研究详情可手动确认观点，填写论点、失效条件、复核日与复核记录，支持失效/归档和同股报告差异对照。复核到期只是页面状态，不会自动定时调用模型或发单。

市场、主题、期权、新闻、ETF申赎视图可主动附加来源快照到目标公司研究，启动前可预览或移除。ETF是背景资料，核心个股研究仍须确认目标公司股票；附加资料进入所有角色共享上下文，不自动替代核心取证。捕获时间晚于研究日期的资料会被拒绝；历史研究只能选用当时已留存快照。没有浏览即自动纳入的隐式行为。

`/api/v1/health`仅表示API存活；`/api/v1/readiness`另查独立worker心跳与当前用户队列。离线、忙碌、排队、租约过期的停滞数量分别显示。部署仍是API和独立worker两个业务进程。

**完整备份与恢复演练**

先完成或取消队列任务。备份打包SQLite一致快照、数据库引用的报告、来源证据、附加资料和已发布完整检查点，文件清单附SHA-256；不读取或打包.env、系统密钥库或OAuth授权文件。以下命令都在项目根执行：

```bash
backend/.venv/bin/python backend/scripts/workbench_recovery.py backup --state-root data/web/development/web --output /private/tmp/tradingagents-recovery.zip
backend/.venv/bin/python backend/scripts/workbench_recovery.py verify --bundle /private/tmp/tradingagents-recovery.zip
backend/.venv/bin/python backend/scripts/workbench_recovery.py restore --bundle /private/tmp/tradingagents-recovery.zip --destination /private/tmp/tradingagents-restored-state
```

恢复目标必须是不存在的新目录，不覆盖正在使用的数据；恢复过程不启动服务。包与恢复文件使用本机私有权限。恢复后保留账号、对象与历史，重写文件根路径，撤销所有浏览器会话及未使用的旧初始化凭证、停用连接、撤销检测状态、清除心跳。已初始化的账号须用原密码重新登录并重新绑定凭据；尚未初始化的备份需在恢复目录生成新的初始化凭证。恢复标记同时禁止继承环境变量或本机ChatGPT订阅的旧local回退；需要在模型设置中显式创建/绑定并检测模型模板。旧代码签名不兼容的检查点仍拒绝恢复执行，已完成报告可读。
